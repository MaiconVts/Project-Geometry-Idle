# QA & Performance Plan

## 📌 Propósito deste Documento
Define os critérios de qualidade e performance. Como garantimos que o jogo não vai travar o PC/Celular do usuário?

## 📝 O que será documentado aqui:
* **Metas de Performance:** FPS alvo (60/30), Uso máximo de RAM, Draw Calls máximos.
* **Plano de Testes:** Lista de casos de teste (Smoke Tests, Regression Tests).
* **Stress Testing:** Testes de limite (Quantas setas o jogo aguenta antes de cair o FPS?).
* **Dispositivos Alvo:** Configurações mínimas de PC e requisitos para Mobile futuro.
